# Troubleshooting

- **"Refused: This plugin is not entitled to …"**: a deployment admin
  entitles it on Data sources.
- **The blotter is empty**: no order is on an account you may read; a
  deployment admin grants accounts.
- **No bars**: the lake holds none of that instrument yet at any bar length, in the chart's window of its last 500 bars of each. The chart asks again every 30 seconds.
